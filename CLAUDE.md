# Claude Code — Everything You Need to Know

Reference repository: comprehensive guide to Claude Code. Tutorials, prompt engineering, MCP servers, specialized agents, workflows. Designed for viewing in Obsidian.

## Structure
- `README.md` — Master guide (main content)
- `Images/` — Screenshots, diagrams, icons
  - `Agents/`, `MCP/`, `Icons/` — Categorized images
- `mcp-servers/` — MCP server setup guides
  - `memory.md`, `playwright.md`, `sequential-thinking.md`, `serena.md`
- `specialized-agents/` — Agent prompt templates and workflows
  - `system-prompts/` — Agent system prompts
  - `Descriptions/` — Agent role descriptions
  - `.canvas` files — Obsidian canvas workflow diagrams

## Conventions
- Documentation repo — no runnable code
- Obsidian-flavored Markdown (canvas files, internal links)
- Images referenced from `Images/` directory

## File Ownership (parallel work)
- `mcp-servers/` — each server guide is independent
- `specialized-agents/` — each agent file is independent
- `Images/` — static assets, independent
- `README.md` — monolithic, coordinate edits

## Gotchas
- Canvas files (`.canvas`) require Obsidian to view properly
- This is documentation only — no build, test, or deploy steps
